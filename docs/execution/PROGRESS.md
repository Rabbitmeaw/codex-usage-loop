## 当前批次

B44 已完成。根据 2026-07-26 的无屏幕录制实机观察，Codex 公开的窗口和状态输入
能稳定提供位置，但 pet 实际尺寸不会反映到 fallback。实机对比已确认透明容器中心
在普通位置与用户期望的视觉 X 对齐；容器越过左右屏幕边缘时则改用代理 pet 中心，
保持边缘跟随。当前活动状态只公开 pet 锚点、不公开实时尺寸，因此未测量的 `anchoredFallback`
围绕模式不再把固定代理框中心当作可见 pet 中心：默认直径保持约 157 pt，圆环顶边比
pet 锚点高 16 pt，圆环直径由用户通过“围绕 pet 的圆环大小”菜单调节。触及左右边缘时使用代理 pet 中心
而不再施加固定 X 偏移；圆环直径滑杆范围从 75%–150% 扩展为 25%–250%。该规则不影响已取得像素测量的路径、持久化回退与侧边圆环，已在真实无授权 pet 会话中完成视觉确认。Windows 同步同一回退策略及 25%–250% 尺寸范围；本机缺少 Windows .NET 工具链，Windows 构建与集成验证留待 Windows CI／实机执行。
