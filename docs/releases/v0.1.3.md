# CodexUsageLoop v0.1.3

v0.1.3 收口 macOS 与 Windows 在未使用像素级测量时的围绕 pet 圆环回退体验：保持稳定的本机锚点跟随，同时把无法由 Codex 公开状态得知的实际 pet 尺寸明确交给用户选择是否微调。

## 主要变化

### macOS

- 未授予屏幕录制权限、macOS 13 或像素捕获暂时不可用时，普通位置以当前任务卡透明容器的水平中心定位；任务卡贴到左右屏幕边缘时，改用 pet 代理框的水平中心。
- 回退围绕圆环使用更紧凑的默认估算直径，圆环顶边相对 pet 锚点提高 16 pt，减少默认视觉偏右下。
- 围绕 pet 圆环大小现在可在 25%–250% 连续调整。默认 100% 可直接使用；如需更贴近自己的 pet 视觉大小，用户可选择缩小或放大圆环，设置会保存且不会改变 pet 本身。
- 已授权的 macOS 14+ 像素级定位继续以实测可见 pet 边界确定圆心和直径，未被此回退规则改变。

### Windows

- Windows 同步普通位置、左右屏幕边缘和顶部的回退定位规则；状态含有显式 mascot 矩形时，保留原有位置与尺寸计算。
- 围绕 pet 圆环大小预设扩展为 25%、50%、100%、150% 和 250%。默认 100% 可直接使用，用户可按视觉偏好选择其他预设，不会改变 pet 本身。

## 验证

- macOS：72 项 Swift 测试、Release 构建和严格签名校验通过；无屏幕录制授权的真实 pet 会话已检查普通位置及左右边缘的回退跟随和视觉对齐。
- Windows：本次变更由 Windows CI 的 .NET 10 构建、Core 检查、单文件打包和原生 app-server／窗口生命周期集成门禁验证；本机 macOS 环境没有 .NET 工具链，未将其表述为本机 Windows 实机测试。
- macOS 回归环境为 ChatGPT／Codex Desktop `26.721.41059`（build `5848`，bundle ID `com.openai.codex`）与 Codex CLI `0.136.0`。本 Release 仅承诺这组已记录环境和本仓库的能力契约，不假定后续 Codex Desktop／CLI 版本兼容。

## 本地处理与权限边界

CodexUsageLoop 不读取认证文件，不保存或上传截图，也不发起自有 HTTP 请求。用量仅经本机 `codex app-server --stdio` 读取；Codex CLI／app-server 自身的网络行为，以及用户明确打开 Releases 后的默认浏览器连接，属于各自独立边界。

macOS 14+ 的像素级定位仅在用户从菜单主动请求并自行授予屏幕录制权限后启用；定位图像只在 CodexUsageLoop 进程内存中分析。屏幕录制仍是可访问屏幕内容的敏感系统权限，这些实现边界不是“绝对安全”或“零风险”承诺。未授权时仍可按本机窗口和布局锚点稳定跟随，并可选择手动调整圆环大小。

## 下载与签名

macOS 工件仅使用 ad-hoc 签名，未使用 Developer ID 身份签名且未公证；Windows 工件没有 Authenticode 发布者签名。请仅从官方 Release 下载，核对 tag、提交和相邻 SHA-256 文件，不要关闭 Gatekeeper 或其他系统安全机制。更多说明见 [Release 安全说明](../RELEASE_SECURITY.md)。
