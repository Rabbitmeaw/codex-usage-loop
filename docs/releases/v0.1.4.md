# CodexUsageLoop v0.1.4

v0.1.4 修复两类随 Codex 更新暴露的问题：macOS 上“没有找到 Codex 可执行文件”导致无法监控额度，以及 Codex 桌面端把宠物改为 native 页渲染后，围绕 pet 圆环偏右下、不再随宠物大小缩放。

## 主要变化

### 修复可执行文件发现（macOS + Windows）

- 新版 ChatGPT.app 把内置 Codex 从 `Contents/Resources/codex` 迁到 `Contents/Resources/codex-cli/bin/codex`，旧固定路径列表因此全部落空。macOS 新增自动定位：依次搜索双端桌面应用的新旧内置布局、Homebrew、`~/.local/bin`、nvm 各版本（取最新）、volta／asdf／mise／pnpm，最后以登录 shell `command -v codex` 兜底（2 秒超时）；定位结果缓存，失败时报错附带实际搜索过的位置。
- Windows 同步在静态候选与运行中进程扫描中加入 `resources\codex-cli\bin\codex.exe` 新布局，并缓存定位结果避免每次刷新重扫进程。

### 修复围绕 pet 圆环定位（macOS + Windows）

- Codex 桌面端更新后，独立的宠物透明窗口从系统窗口列表消失，宠物改为主窗口内渲染，持久化状态不再包含宠物尺寸。应用改为从 `config.toml` 读取 `avatar-overlay-mascot-width-px`，并按 Codex 渲染器同一公式（高 = ceil(宽 × 208/192)，宽限 80–224）计算宠物真实尺寸；用户调整宠物大小后，圆环在约 1 秒内自动跟随缩放并保持在宠物正中。
- 移除旧版透明 overlay 时代的回退顶对齐规则（圆环顶边高于锚点 16pt、任务卡容器中心、屏幕边缘代理）；“围绕 pet”圆环在实测、锚点回退与持久化回退下统一以宠物框中心为圆心。状态里旧格式的显式 mascot 矩形仍优先，兼容旧版 Codex。

## 验证

- macOS：85 项 Swift 测试、Release 构建和严格签名校验通过；本机已实测 `codex app-server --stdio` 拉起与额度跟踪恢复，并经用户实机视觉验收圆环回到宠物正中且随宠物缩放。
- Windows：本次变更由 Windows CI 的 .NET 10 构建、Core 检查、单文件打包和原生 app-server／窗口生命周期集成门禁验证；本机 macOS 环境没有 .NET 工具链，未将其表述为本机 Windows 实机测试。
- 本次回归的 macOS 环境：ChatGPT Desktop `26.924.22138`（build `11645`，内置 codex-cli `0.158.0-alpha.2.1`）与 Codex CLI `0.153.4`（npm/nvm）。本 Release 仅承诺这组已记录环境和本仓库的能力契约，不假定后续 Codex Desktop／CLI 版本兼容。

## 本地处理与权限边界

CodexUsageLoop 不读取认证文件，不保存或上传截图，也不发起自有 HTTP 请求。用量仅经本机 `codex app-server --stdio` 读取；Codex CLI／app-server 自身的网络行为，以及用户明确打开 Releases 后的默认浏览器连接，属于各自独立边界。

macOS 14+ 的像素级定位仅在用户从菜单主动请求并自行授予屏幕录制权限后启用；定位图像只在 CodexUsageLoop 进程内存中分析。屏幕录制仍是可访问屏幕内容的敏感系统权限，这些实现边界不是“绝对安全”或“零风险”承诺。未授权时圆环按本机窗口和布局锚点稳定跟随，并随宠物大小自动调整。

## 下载与签名

macOS 工件仅使用 ad-hoc 签名，未使用 Developer ID 身份签名且未公证；Windows 工件没有 Authenticode 发布者签名。请仅从官方 Release 下载，核对 tag、提交和相邻 SHA-256 文件，不要关闭 Gatekeeper 或其他系统安全机制。更多说明见 [Release 安全说明](../RELEASE_SECURITY.md)。
