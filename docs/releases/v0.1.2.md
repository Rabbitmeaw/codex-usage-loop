# CodexUsageLoop v0.1.2

这是一次跨平台预发布，集中交付 Windows 原生版本、刷新职责修正、手动
Releases 入口，以及 macOS 13 像素定位能力门禁。

## 主要变化

- 新增 Windows 10 22H2／Windows 11 x64 原生伴随应用。
- macOS 与 Windows 的“立即刷新”只刷新用量；pet 位置／大小重测保持独立。
- 移除 macOS 的 ⌘R 菜单快捷键，避免与浏览器等前台应用冲突。
- 两个平台新增“在浏览器查看 GitHub Releases…”；应用自身不检查、下载或
  安装更新。
- 排除 Computer Use／Software Cursor 辅助窗口，避免圆环误跟随错误窗口。
- macOS 13 明确使用窗口几何估算；macOS 14+ 保持用户主动授权的像素定位。

## 验证

- macOS：54 项 Swift 测试、Release 构建、严格签名校验通过。
- Windows：29 项 Core 检查、原生 app-server／窗口生命周期集成、Release
  单文件打包通过。
- 本次 macOS 环境检测到 Codex CLI `0.136.0`。
- macOS 13 实机估算定位 smoke、Windows 真实 Codex CLI 兼容验证仍待补。

## 安全与工件

macOS 工件为 ad-hoc 签名且未公证；Windows 工件没有 Authenticode 发布者
签名。请核对 tag、提交和相邻 SHA-256 文件，不要关闭 Gatekeeper 或其他系统
安全机制。
