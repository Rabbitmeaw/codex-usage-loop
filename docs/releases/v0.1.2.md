# CodexUsageLoop v0.1.2

v0.1.2 是 v0.1.1 之后的完整跨平台正式版本，集中交付 Windows 原生伴随应用、
两端一致的刷新与手动 Releases 入口，以及 macOS 定位稳定性和系统能力门禁。

## 主要变化

### macOS

- “立即刷新”现在只刷新用量，不再隐式重测 pet；同时移除会与浏览器等前台
  应用冲突的 ⌘R，并在刷新中或失败但保留旧数据时显示明确状态。
- “重新检测宠物位置/大小”继续独立重测几何。Computer Use 活跃且已有可信
  pet 几何时，圆环保持原位置和大小；此时手动重测会在圆环附近短暂提示检测
  已暂停，会话结束后自动恢复跟踪。
- 排除 Computer Use、Computer Use Controls 和 Software Cursor 等辅助窗口，
  避免把它们识别为 pet。
- macOS 13 明确使用窗口几何估算，不显示像素定位授权入口，也不会调度
  ScreenCaptureKit；macOS 14+ 仍由用户从菜单主动决定是否启用像素级定位。

### Windows

- 新增 Windows 10 22H2／Windows 11 x64 原生伴随应用，使用 .NET 10 与 Win32
  分层窗口提供圆环、用量卡片、通知区域菜单、点击穿透和自由拖动。
- 使用 Per-Monitor V2 DPI 与物理像素几何，提供适配 Windows 10／11 的原生
  深色卡片、显示器边界约束及按 DPI 缩放的圆环和字体。
- pet 定位优先读取本机 GUI 几何状态，状态不可用时回退到可见的
  Codex／ChatGPT 窗口；只读取定位所需字段，不扩大到认证数据。
- “立即刷新”只请求最新用量，“重新检测宠物位置/大小”独立重查几何；两者
  都不注册快捷键。
- Windows 商店版 Codex GUI 的内置 CLI 当前不能由普通桌面进程直接启动。
  实时额度需要另行安装官方 Codex CLI 或设置 `CODEX_EXECUTABLE`；没有独立
  CLI 时，圆环和本地交互仍可使用。

### 两个平台

- 新增“在浏览器查看 GitHub Releases…”。只有用户点击后才会打开默认浏览器；
  应用自身不检查、下载或安装更新。

- macOS：64 项 Swift 测试、Release 构建和严格签名校验通过；Computer Use
  实机检查覆盖活动期间冻结、重测暂停提示和会话结束后自动恢复。
- Windows：29 项 Core 检查、原生 app-server／窗口生命周期集成和 Release
  单文件打包通过。
- macOS 实机回归环境为 ChatGPT／Codex Desktop `26.721.41059`
  （build `5848`，bundle ID `com.openai.codex`）与 Codex CLI `0.136.0`；
  已覆盖真实用量读取、pet 定位和 Computer Use 会话行为。
- Windows 真实 Codex CLI 兼容回归尚未完成，因此 v0.1.2 不对未记录的

- macOS 13 的能力门禁已有自动化覆盖，但实机估算定位 smoke 尚未完成；
  Windows 混合 DPI 多显示器拓扑仍需补充更多实机验证。

## 本地处理与权限边界

CodexUsageLoop 不读取认证文件，不保存或上传截图，也不发起自有 HTTP 请求。
用量仅经本机 `codex app-server --stdio` 读取；Codex CLI／app-server 自身的
网络行为，以及用户明确打开 Releases 后的默认浏览器连接，属于各自独立边界。

macOS 14+ 的像素级定位仅在用户从菜单主动请求并自行授予屏幕录制权限后启用；
定位图像只在 CodexUsageLoop 进程内存中分析。屏幕录制仍是可访问屏幕内容的
敏感系统权限，这些实现边界不是“绝对安全”或“零风险”承诺。macOS 13 或未
授权时使用估算定位，应用仍可运行。

## 下载与签名

正式版替换了曾指向提交 `2b5c3c8` 的同版本预发布。该预发布的工件及
SHA-256 已作废；已下载预发布的用户应重新下载，并只以当前正式 Release
页面的 tag、提交、`SHA256SUMS.txt` 和 `RELEASE_METADATA.txt` 为准。

macOS 工件仅使用 ad-hoc 签名，未使用 Developer ID 身份签名且未公证；
Windows 工件没有 Authenticode 发布者签名。请仅从官方 Release 下载，
核对 tag、提交和相邻 SHA-256 文件，不要关闭 Gatekeeper 或其他系统安全机制。
更多说明见 [Release 安全说明](../RELEASE_SECURITY.md)。
