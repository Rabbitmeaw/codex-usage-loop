# 用户手册

CodexUsageLoop 是 Codex pet 的本地菜单栏伴随应用：它从本机 Codex app-server 读取用量，并在 pet 附近展示单环或双环。应用不接管 pet，也不保存屏幕画面。

## 系统要求与安装

- macOS 13 或更高版本。
- Xcode Command Line Tools。
- 已登录的 Codex CLI 或 Codex Desktop，且能在终端运行 `codex`。
- macOS 14 及更高版本可在授权后使用 ScreenCaptureKit 进行像素级 pet 定位；macOS 13 始终使用窗口几何估算。

### 从源码构建并启动

```bash
zsh scripts/build-app.sh
zsh scripts/restart-app.sh
```

### 安装到 Applications 与启动台

```bash
zsh scripts/install.sh
```

脚本会构建、安装到可写的 Applications 目录并注册 Launch Services，因此首次安装后也能在启动台和 `/Applications` 中看到应用。若本机存在 Apple Development 签名，安装脚本会优先使用它，以提高后续更新仍保留 macOS 隐私授权的稳定性；这不是 Developer ID 分发签名。

### 供终端或自动化工具执行的安装

自动化工具或本地 agent 可在仓库根目录执行以下非交互命令：

```bash
zsh scripts/install.sh --with-login-agent
```

它会安装应用并注册登录 companion。命令只操作本机应用与当前用户的 LaunchAgent；仍需要用户自行在菜单中决定是否启用“随 Codex 宠物启动”，并自行决定是否授予屏幕录制权限。

### 随登录待命与随 Codex pet 启动

`--with-login-agent` 仅表示应用在登录后待命，不会替你改变应用内偏好。启动应用后，从菜单勾选 **随 Codex 宠物启动**：

- Codex Desktop 运行时，应用读取用量并跟随 pet。
- Codex Desktop 退出时，应用暂停用量读取与定位，悬浮层隐藏。
- pet 暂时隐藏但 Codex Desktop 仍运行时，圆环始终保留；**始终显示用量卡片** 只决定详情卡是否同时保留。圆环优先沿用最近一次位置；若没有可用位置，则显示在屏幕左下角的安全位置。

如需移除登录 companion：

```bash
zsh scripts/uninstall-launch-agent.sh
```

## 首次使用

1. 启动 Codex Desktop，并确保 pet 已显示。
2. 启动 CodexUsageLoop。它会读取本机 `codex app-server --stdio` 的用量数据。
3. 先确认圆环是否出现在 pet 周围；如刚调整过 pet，选择 **重新检测宠物位置/大小**。
4. 如需缩放、任务卡变化及屏幕边缘时的最高定位精度，请完成下文的屏幕录制授权。

应用是 accessory app：不出现在 Dock，也不会抢焦点。所有控制项都在菜单栏双环图标中。

## 像素级定位与屏幕录制权限

### 它解决什么问题

Codex 的透明 pet 容器并不总等于实际可见 pet 的边界。未授权时，应用根据本机窗口几何和当前布局锚点跟随 pet；它会给围绕模式一个默认对齐和直径，但无法得知 Codex 未公开的实时 pet 缩放。默认值已可直接使用；若希望视觉大小更贴近自己的 pet，可选地打开 **围绕 pet 的圆环大小**，先保持 100%，pet 在环内显得太小时向左缩小，圆环太紧时向右放大，直到视觉留白合适；设置会保存，且不会改变 pet 本身。

在 macOS 14+ 获得屏幕录制权限后，应用会测量透明窗口中实际可见 pet 的像素边界：

- 围绕 pet 的圆环圆心直接使用实测 pet 圆心。
- 圆环直径随实测 pet 的实际尺寸改变。
- 初次定位或 pet 容器／布局变化时采集 3 个短时样本并取中位数，以减少动画边界抖动。
- 稳态使用缓存，不持续截图；屏幕画面只在本机内存中分析，不保存、不上传。

### 如何授权

1. 打开菜单栏图标。
2. 查看 **屏幕录制：未授权（使用估算）**。
3. 选择 **启用像素级定位…**。
4. 按 macOS 的系统流程打开“系统设置 → 隐私与安全性 → 屏幕录制”，为 CodexUsageLoop 开启授权。
5. 如果 macOS 要求“退出并重新打开”，先完成该系统步骤，再重新启动 CodexUsageLoop。
6. 回到菜单确认状态变为 **屏幕录制：已授权（像素级定位）**，然后选择 **重新检测宠物位置/大小**。

应用绝不会在启动时自动请求该权限，也不会显示与系统“退出并重新打开”提示竞争的应用内模态弹窗。授权提示只会在你主动选择菜单项后出现。

如果系统设置显示开关已打开、菜单仍显示未授权，请关闭再重新开启该开关，然后彻底退出并重新打开应用。菜单显示的是当前运行进程实际检测到的状态。

## 菜单功能与使用方法

| 功能 | 何时使用 | 操作与结果 |
| --- | --- | --- |
| 始终显示用量卡片 | 希望不悬停或 pet 隐藏时仍看到详情 | 只控制用量卡：勾选后始终展示卡片，未勾选时仅在悬停 pet 圆环时显示。pet 隐藏但 Codex 仍运行时，圆环始终保留。 |
| 自由拖动位置 | 临时把圆环放到指定位置 | 勾选后直接拖动圆环。关闭后立即恢复自动跟随；默认悬浮层点击穿透。 |
| 圆环固定位置 | 想改变圆环相对 pet 的位置 | 在 **围绕 pet**、**左侧（垂直居中）**、**右侧（垂直居中）** 中选择。 |
| 围绕 pet 的圆环大小 | 想让围绕模式更紧凑或更醒目，或可选地适配未授权时自己的 pet 大小 | 默认 100% 可直接使用。若想微调，pet 显得太小就向左缩小，圆环太紧就向右放大。滑杆可在 25%–250% 间实时预览，选定值会保存；**恢复默认（100%）** 回到默认比例。双环间距和直径保持比例一致，pet 本身不会被修改。 |
| 圆环颜色 | 想自定义主题颜色 | 分别选择 **外环颜色…** 与 **内环颜色…**，原生颜色面板会即时预览；颜色按 sRGB 保存。**恢复默认蓝绿** 恢复项目配色。 |
| 菜单栏图标 | 需要更醒目的菜单栏标识 | 选 **原色（蓝绿）** 显示双环原色；选 **单色（跟随系统）** 让 macOS 按深浅色自动提供对比。 |
| 随 Codex 宠物启动 | 希望 Codex 不运行时减少后台工作 | 先按上文安装登录 companion，再勾选该项；它只控制 Codex Desktop 退出时是否暂停，不决定 pet 隐藏时的显示。 |
| 演示双环 | 想预览两个额度窗口的视觉效果 | 仅在真实数据不是双环时可用；真实双环出现后会禁用，模拟数据不会覆盖真实数据。 |
| 立即刷新 | 想立即刷新额度 | 仅异步请求最新用量；卡片显示刷新中或失败状态，失败时保留上次数据。为避免与前台应用冲突，不设置快捷键。 |
| 重新检测宠物位置/大小 | 刚拖动或缩放 pet，或刚完成授权 | 清除像素测量与失败重试状态并重新定位。为避免闪烁，旧实测几何会保留到新结果完成；授权时通常在下一次 1 秒轮询采用新的三帧实测。Computer Use 会话活跃时重测暂停，圆环附近会短暂提示，结束后自动恢复定位。 |
| 启用像素级定位… | 需要精确尺寸与圆心 | 仅由此菜单项发起 macOS 屏幕录制授权；详见上一节。 |
| 在浏览器查看 GitHub Releases… | 想查看新版本、变更说明或下载文件 | 仅在点击后由 macOS 默认浏览器打开官方 Releases；应用自身不检查、下载或安装更新。 |
| 退出 | 结束应用 | 停止用量读取、定位计时器和悬浮层。 |

## 用量显示与双环

- 应用从本机 app-server 读取可用的限额窗口。单个窗口显示单环；两个真实窗口显示双环。
- 环的颜色表示剩余比例，详情卡显示剩余比例、重置时间与最近更新时间。
- **立即刷新** 可手动请求新值；正常情况下用量每 30 秒刷新一次。
- app-server 无法连接或没有有效数据时，应用显示错误状态并保留已有界面偏好；不会伪造额度。

## 能耗与隐私

### 能耗策略

- 用量每 30 秒刷新一次。
- 宠物窗口几何每秒做一次轻量检查，以便在拖动后跟随。
- 已授权的像素捕获不是每秒执行：成功测量会缓存，只有首次定位、容器几何或布局标识变化时才重新测量。
- 无法定位时，像素检测按 5 秒退避；只处理评分最高的 pet 候选窗口。

### 隐私边界

- 仅通过本机 `codex app-server --stdio` 读取用量。
- 不读取、解析或上传 `~/.codex/auth.json`。
- 不上传用量、窗口信息或屏幕画面；截图仅在内存中用于本地定位，随后丢弃。
- CodexUsageLoop 不发起自有 HTTP 请求；Codex CLI／app-server 自身可能有独立
  的网络行为，但屏幕画面不会传给它。
- 只有用户选择“在浏览器查看 GitHub Releases…”时，macOS 才会在默认浏览器
  打开官方发布页。浏览器和 GitHub 构成另一个独立边界，CodexUsageLoop 不会
  通过该路径发送用量、窗口信息或屏幕画面。
- 不自动检查、下载或安装更新。
- 没有全局鼠标右键监听，也不会干扰其他应用输入。

屏幕录制仍是可以访问屏幕内容的敏感系统权限。上述当前实现边界不能等同于
绝对零风险；请确认软件来源、理解定位用途后自行决定是否授权。拒绝或撤销权限
不会阻止应用运行，只会改用窗口几何估算。

## 已知边界与排障

### 圆环没有出现或没有跟随

1. 确认 Codex pet 当前可见。
2. 选择 **重新检测宠物位置/大小**。
3. 若已调整 pet 大小、任务卡状态或位置，请等待一次重新测量完成。
4. 在 macOS 14+，建议授予屏幕录制权限后再次重新检测。

### 宠物靠近左右屏幕边缘

未授权时，圆环会在普通位置和左右边缘跟随 Codex 公开的布局锚点；但它无法验证可见轮廓或实时 pet 大小。默认直径可继续使用；若你觉得直径不合适，可选地用 **围绕 pet 的圆环大小** 按上面的 100% → 缩小／放大方式调节，不需要移动 pet。授权后的像素级定位会使用可见 pet 边界，因此可自动适配实际大小。

### 想隐藏 pet 但保留项目显示

只要 Codex Desktop 仍在运行，pet 隐藏后圆环会继续显示：优先保持最后一次 pet 位置；若没有可用位置，则显示在屏幕左下角的安全位置。勾选 **始终显示用量卡片** 可同时保留详情卡；不勾选则只保留圆环。开启“随 Codex 宠物启动”且 Codex 整体退出后，两个面板都会隐藏。

“随 Codex 宠物启动”不是这个开关：它只决定 Codex Desktop 整个退出时，应用是否暂停用量读取与定位。若希望 Codex 退出后应用也继续工作，请取消勾选“随 Codex 宠物启动”，同时开启“始终显示用量卡片”。

### 圆环位置或直径仍有偏差

若菜单显示 **屏幕录制：未授权（使用估算）**，默认圆环仍可正常跟随。若希望更贴近自己的 pet 视觉大小，可选地用 **围绕 pet 的圆环大小** 从 100% 开始调节：pet 显得太小就缩小圆环，圆环太紧就放大圆环。若需要自动贴合实际 pet 尺寸，再选择 **启用像素级定位…** 完成授权，确认菜单显示 **屏幕录制：已授权（像素级定位）** 后选择 **重新检测宠物位置/大小**。若系统设置已授权但菜单仍显示未授权，请按“像素级定位与屏幕录制权限”章节重新开关授权并重启应用。

### 没有显示用量

确认终端可运行 `codex` 且当前账号已登录。选择 **立即刷新**；若 app-server 暂时不可用，应用不会伪造用量。

### 菜单栏中出现两个图标

应用有单实例保护。若旧的开发实例仍在运行，使用仓库根目录的 `zsh scripts/restart-app.sh`，该脚本会先结束旧实例，确认退出后再启动新实例。

### macOS 阻止打开下载的应用

开源 Release 不做 Developer ID 签名或 Apple 公证。请只从官方 GitHub Release 下载，核对 SHA-256 和发布标签；确认来源后在“系统设置 → 隐私与安全性”选择“仍要打开”。不要关闭 Gatekeeper，也不要运行来历不明的绕过脚本。详见 [Release 安全说明](RELEASE_SECURITY.md)。
