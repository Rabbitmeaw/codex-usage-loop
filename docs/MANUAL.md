# 用户手册

## 安装与启动

项目要求 macOS 13 或更高版本、Xcode Command Line Tools，以及已登录的 Codex CLI 或 Codex Desktop。macOS 13 使用窗口几何估算；macOS 14 及更高版本在已授权屏幕录制时可使用像素级宠物定位。

```bash
zsh scripts/build-app.sh
open "dist/CodexUsageLoop.app"
```

应用为菜单栏伴随工具，不会出现在 Dock。启动后从菜单栏的双环图标进入所有控制项。

## 首次使用

1. 启动 Codex Desktop，并显示宠物。
2. 启动 CodexUsageLoop；它会从本机 `codex app-server` 获取用量。
3. 如需精确识别透明宠物窗口内的实际边界，在 macOS“系统设置 → 隐私与安全性 → 屏幕录制”中授权 CodexUsageLoop，然后点击“重新检测宠物位置/大小”。

未授予屏幕录制权限时，应用仍会使用宠物容器的窗口几何估算位置；不会主动弹出授权请求，也不会保存或上传屏幕画面。此模式能满足基本跟随，但在非默认布局、宠物实际边界与容器比例不同，或任务卡片改变位置时，圆环的位置和直径可能出现偏差。

为获得与宠物边界更准确的贴合效果，推荐在 macOS“系统设置 → 隐私与安全性 → 屏幕录制”中授权 CodexUsageLoop；授权后再点击“重新检测宠物位置/大小”。截图仅在本机内存中用于定位，不会被保存或上传。

## 菜单功能

| 功能 | 作用 |
| --- | --- |
| 始终显示用量卡片 | 即使宠物暂时不可见，也保留圆环和卡片。围绕 pet 时卡片在圆环右侧；左右侧圆环时卡片在圆环下方。 |
| 自由拖动位置 | 允许拖动圆环；关闭后恢复跟随宠物。 |
| 圆环固定位置 | 选择围绕 pet、左侧或右侧。 |
| 圆环颜色 | 用 macOS 原生颜色面板分别设置外环和内环；颜色会以 sRGB 保存。“恢复默认蓝绿”会还原项目默认配色。 |
| 菜单栏图标 | 选择原色蓝绿，或随系统深浅色变化的单色图标。 |
| 演示双环 | 仅在真实用量未返回两个窗口时可用；真实双环出现后自动禁用。 |
| 立即刷新 | 立即请求最新用量，并同时重新检测宠物位置。 |
| 重新检测宠物位置/大小 | 清除宠物位置缓存，适用于调整宠物大小或位置之后。 |

## 能耗与隐私

- 用量每 30 秒刷新一次；宠物窗口几何每 1 秒检查一次。
- 成功定位后会复用结果；定位失败会等待 5 秒再尝试截图，且只会对评分最高的候选窗口执行像素检测。
- 用量通过本机 app-server 读取；不读取认证文件，不上传数据，不保存截图。

## 常见问题

### 圆环没有跟随宠物

先确认 Codex 宠物可见，再点击“重新检测宠物位置/大小”。如果宠物位于透明窗口的非默认位置，请授予屏幕录制权限后再次重新检测。

### 没有显示用量

确认终端可运行 `codex` 且当前账号已登录。应用会保留上一次有效展示；也可从菜单选择“立即刷新”。

### macOS 阻止打开下载的应用

本项目的开源 Release 不做 Developer ID 签名或 Apple 公证。请只从官方 Release 下载，核对 SHA-256 和发布标签；确认来源后在“系统设置 → 隐私与安全性”选择“仍要打开”。不要关闭 Gatekeeper，也不要运行来历不明的绕过脚本。详见 [Release 安全说明](RELEASE_SECURITY.md)。
